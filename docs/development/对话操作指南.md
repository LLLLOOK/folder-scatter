# 对话操作指南（每个对话怎么走、出问题怎么办）

> ⚠️ 历史归档：重构对话流程已结束，`文件处理-新版` 已于 2026-10-08 删除。后续维护直接开 `文件处理-重构` 并读 `agents.md` 即可，无需再按本文档走多对话流程。

> 配套文档：同目录《操作手册.md》（提示词模板）、《新版修复对比清单.md》（进度账本）。
> 核心原则：**成果都在文件里，不在聊天记录里。** 你基本不需要复制对话内容，
> 唯一需要"人肉搬运"的只有**复核意见**这一种东西。

## 总规则

- 所有新对话：工作空间一律打开 `<本项目目录>`
- 模型分工：Kimi-K3 执行（写代码）｜深度求索PRO 复核（挑错）｜千问3.8MAX 仲裁（裁判）｜GLM 5.3 备用
- 每个对话要发的提示词：复制《操作手册.md》第五部分对应段落
- 进度看哪：《新版修复对比清单.md》的"移植状态"列（对话 5 会自动回填）
- 旧版 `<旧版项目目录>\` 和新版 `文件处理-新版\` 全程只读，谁都别动

---

## 对话 2（复核清单 · 深度求索PRO）

**你做**：新开对话 → 深度求索PRO → 工作区 `文件处理-重构` → 发手册"对话 2"提示词。

**它产出**：文字结论（每项"属实/误报/漏项/存疑"）。不改任何文件。

- ✅ 全部"属实" → 不用复制任何东西，直接开始对话 3。
- ⚠️ 有异议 → 新开 Kimi-K3 对话，发：

```
对比清单复核有异议，请核对后修订清单文件
<本项目目录>\新版修复对比清单.md。
复核意见如下：【粘贴 DeepSeek 的异议】
同意的就改清单，不同意的说明理由。改完输出修订摘要。
```

改完**再开一次**对话 2 重复核，直到全票通过。

---

## 对话 3（结构拆分 · Kimi-K3）

**你做**：新开对话 → Kimi-K3 → 发手册"对话 3"提示词。

**它产出**：`文件处理-重构` 里出现代码文件（`main.py`、`core/`、`ui/` 等）+ 拆分说明。

- ✅ 顺利完成 → 不用复制任何东西，直接开对话 4。
- ⚠️ 中途报错 → 把报错原文发回**同一个对话** + `报错了，请分析修复并继续`。

---

## 对话 4（复核拆分 · 深度求索PRO）

**你做**：发手册"对话 4"提示词。

**它产出**：文字结论"通过/不通过+差异清单"。不改文件。

- ✅ 通过 → 直接开对话 5。
- ⚠️ 不通过 → 新开 Kimi-K3 对话，发：

```
结构拆分复核未通过，请逐条修复：
【粘贴 DeepSeek 的差异清单】
基准仍是旧版 <旧版项目目录>\main-1.py（只读），
修复范围仅限当前工作区。修完重新跑 py_compile 和 offscreen 冒烟。
```

修完再开对话 4 重复核，直到通过。

---

## 对话 5（移植修复 · Kimi-K3）

**你做**：发手册"对话 5"提示词。

**它产出**：修改 `core/`、`undo/` 等模块 + 新建 `tests/` 测试 + **自动回填清单"移植状态"列**。

- ✅ 完成 → 直接开对话 6。
- 💬 特殊情况：做到 A4/B1/B3 这几条"取神不取形"的，它会先给你一份"对接说明"——你回复 `可以，继续` 即可（看不懂没关系，对话 6 会替你把关）。
- ⚠️ 报错 → 同对话发报错原文 + `请修复并继续`。

---

## 对话 6（终复核 · 深度求索PRO）

**你做**：发手册"对话 6"提示词。

**它产出**：逐项"通过/不通过" + 整体结论。

- ✅ 全部通过 → 完工。双击 `文件处理-重构` 里的 bat，手动点点界面确认和旧版一样，收工。
- ⚠️ 有不通过 → 新开 Kimi-K3 对话，发：

```
移植终复核有未通过项，请修复：
【粘贴不通过项及原因】
修复后重跑相关测试。
```

修完再开对话 6 重复核，直到全过。

## 千问什么时候上场（只有一种情况）

DeepSeek 说"这么改"，Kimi 说"它说得不对"，两边僵住——把**双方原话**都复制下来，新开千问3.8MAX对话，发：

```
请你当裁判。两个模型对同一问题结论相反。

背景：旧版软件 <旧版项目目录>\main-1.py，
新版在 <新版项目目录>\src\scatterkit\，
施工区在 <本项目目录>\（里面有操作手册.md和
新版修复对比清单.md，请先读）。

甲方（执行方）意见：【粘贴 Kimi 的原话】
乙方（复核方）意见：【粘贴 DeepSeek 的原话】

请独立查看相关代码后给出最终裁定：谁对、为什么、应该怎么做。
```

拿到裁定后发给 Kimi-K3：`按这个裁定执行：【粘贴千问结论】`。

## 其他故障

| 情况 | 应对 |
| --- | --- |
| AI 要改旧版/新版的文件 | 立即停止：`这两个目录是只读的，你不许修改。请只在 文件处理-重构 里工作。` |
| 彻底乱套 | 把 `文件处理-重构` 里**除三个 md 文档外**的东西全删掉，按手册重做当前阶段 |
| 拿不准怎么办 | 回到最初那个 Kimi 对话（出清单的那个）把情况发过去问 |

记住：**永远乱不坏，因为旧版一个字节都没动过。**
