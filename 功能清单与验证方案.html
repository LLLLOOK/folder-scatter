① 散开核心（core/ + ui/workers.py）

散开方式

  • 散开深度三档：仅当前层 / 包含子文件夹 / 全部层级
  • 操作方式：移动（剪切）/ 复制（copy 带磁盘空间预检警告）
  • 模拟运行：预览清单、零改动、不抢锁，可在锁占用时执行
  • 多线程执行 + 安全停止：停止后已处理文件保持散开态
  • 同名文件夹递归合并；智能重命名去重（-1、-2 后缀）

冲突处理

  • 覆盖 / 跳过 / 自动重命名 三策略
  • 覆盖前备份旧文件（默认开），撤回时可还原安全
  • 只读目标跳过覆盖，禁止静默裸覆盖/物理删除
  • 新文件落位失败 → 旧文件从备份还原回原位（B3）

筛选过滤

  • 后缀过滤：JPG/PNG/PSD/C4D 复选框 + 自定义后缀（中英文逗号/空格分隔、实时红框校验）
  • 「只散开 / 只排除」黑白名单切换
  • 大文件保护：忽略大于 N MB（复选框门控数字框，默认 500MB，GUI/右键共用设置键）
  • 忽略系统隐藏文件（设置项）

安全防护 安全

  • 磁盘根目录拦截（C:\、D:\ 等直接拒绝）
  • 系统关键目录拦截（环境变量+硬编码，realpath/subst 解析防绕过）
  • 链接 / junction / 挂载点防穿透（GUI 与右键两入口都拦）
  • 长路径 \\?\ 前缀支持；os.remove 失败回退 DeleteFileW（B8）
  • 跨进程散开互斥锁（Windows 命名互斥体）

② 撤回体系（undo/）

  • 栈式撤回：最多 20 批，跨会话持久化 undo_history.json，启动时 pending 合并 + inflight 自愈 + 备份缺失自愈
  • 三类还原：移动 → 还原原位；复制 → 副本送回收站；被覆盖旧文件 → 从备份自动还原
  • 幂等重入（A3）：重复撤回/崩溃重试时已还原项静默跳过不误报，真丢失仍告警
  • 失败留栈：部分项撤回失败批次保留在栈中可重试
  • 账本双保险（B2）：写前留 .bak、主坏从 .bak 恢复、双坏隔离 .corrupt 不静默置空
  • 防伪校验：撤回路径合法性 + 备份路径信任校验，篡改 JSON 无法指向系统目录
  • 备份清理三联动：清空/删除备份 → 引用批次整批出栈 + 主日志 [备份] 块同步 + 设置行移除

③ 备份管理（backup/）

  • 备份布局 <盘>:\散开备份\<批次>\（可见目录；盘根不可写回退父目录 .scatter_backup）
  • 同盘 rename 瞬时备份；B4 落点保留源相对层级
  • 自定义备份目录（含盘根/系统目录校验）
  • 按天保留清理（移回收站）、清理失效备份（所有盘）、设置内逐盘打开/清空
  • 保留期 = 撤回记录生命周期：出栈 / 20 批截断 / 撤回后自动清理

④ 右键菜单与静默模式（win32/menu.py + main.py）

  • 4 个可勾选菜单项：仅当前层散开 / 包含子文件夹散开 / 全部层级散开 / 在软件中打开（可撤回）
  • 带图标、多选支持（MultiSelectModel=Player）、分组分隔线、注册版本号强制刷新
  • 静默散开：无 UI 后台执行，多选排队等锁（10 分钟），Toast 反馈，SHChangeNotify 刷新资源管理器
  • 右键独立的「默认操作方式 / 默认冲突处理」设置，与 GUI 设置解耦
  • 右键多选 10 秒窗口分组合并为「一批撤回」
  • 日志写 silent.log / error.log；pythonw 崩溃写 crash.log

⑤ IPC 进程间同步（ui/ipc_server.py）

  • 右键静默进程 ↔ GUI 实时同步日志与撤回批次
  • done 300ms 防抖合并（防目录树刷新风暴）
  • 应用层 ack + batch_id 幂等去重 + 失败重投（A4）；无 ack 降级写 pending，启动合并
  • 任务栏忙碌进度 + Toast 完成提示

主界面

  • 深 / 浅 / 跟随系统 三档主题（读 Windows 注册表，默认深色）

  • Toast 悬浮通知（右下角，2.5s 淡出）；系统托盘（显示主界面/退出、双击唤出）
  • 任务栏进度条（ITaskbarList3，含 30s 看门狗）
  • 窗口几何记忆、重置窗口、悬停 tooltip 同步状态栏（截断 60 字）

阶段 0 · 环境准备（必做，后续所有用例依赖）

用管理员 PowerShell 执行下面脚本，在 D 盘生成标准测试树（无 D 盘就把 $R 改成其他盘）：

$R = "D:\散测"
Remove-Item $R -Recurse -Force -ErrorAction SilentlyContinue
# 主测试树：三层嵌套 + 多种文件类型 + 冲突 + 隐藏 + 只读
New-Item -ItemType Directory -Force "$R\父目录\子A\子A1","$R\父目录\子B\子B1\子B2","$R\冲突源" | Out-Null
"根jpg"  | Out-File "$R\父目录\根文件1.jpg"
"根txt"  | Out-File "$R\父目录\根文件2.txt"
"a1"     | Out-File "$R\父目录\子A\a1.jpg"
"a2png"  | Out-File "$R\父目录\子A\a2.png"
"a11"    | Out-File "$R\父目录\子A\子A1\a11.txt"
"b1"     | Out-File "$R\父目录\子B\b1.jpg"
"b2psd"  | Out-File "$R\父目录\子B\b2.psd"
"deep"   | Out-File "$R\父目录\子B\子B1\子B2\deep.txt"
"hidden" | Out-File "$R\父目录\隐藏文件.jpg"
"旧内容" | Out-File "$R\父目录\同名.txt"          # 目标已存在（旧）
"新内容" | Out-File "$R\冲突源\同名.txt"           # 用于制造冲突
"ro"     | Out-File "$R\父目录\只读旧.txt"
Set-ItemProperty "$R\父目录\隐藏文件.jpg" -Name Attributes -Value "Hidden"
Set-ItemProperty "$R\父目录\只读旧.txt"  -Name Attributes -Value "ReadOnly"
# 超长路径（>260 字符）
$deep = "$R\长路径" + ("\层级很深很深的目录名" * 18)
New-Item -ItemType Directory -Force $deep | Out-Null
"longpath" | Out-File "$deep\超长路径文件.txt"
# 600MB 大文件（用于大文件忽略用例，不需要可注释掉）
fsutil file createnew "$R\父目录\大文件.bin" 629145600 | Out-Null
Write-Host "测试树已生成：$R"
